[3] MongoDB 실제 연결
====================================================

설치:
npm install mongoose

.env

---------------------------------
MONGO_URI=mongodb://127.0.0.1:27017/dnx
---------------------------------

server.js

---------------------------------
import mongoose from "mongoose";

mongoose.connect(process.env.MONGO_URI)
.then(()=>{
 console.log("Mongo Connected");
});
---------------------------------
