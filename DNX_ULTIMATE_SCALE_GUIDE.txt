
DNX ULTIMATE SCALE PACKAGE

=================================
[1] Docker 컨테이너 배포
=================================

설치:
https://www.docker.com/

Dockerfile

--------------------------------
FROM node:20

WORKDIR /app

COPY . .

RUN npm install

EXPOSE 5000

CMD ["npm","start"]
--------------------------------

실행:
docker build -t dnx .
docker run -p 5000:5000 dnx

=================================
[2] NGINX 리버스 프록시
=================================

설치:
https://nginx.org/

nginx.conf

--------------------------------
server {
  listen 80;

  location / {
    proxy_pass http://localhost:5173;
  }

  location /api {
    proxy_pass http://localhost:5000;
  }
}
--------------------------------
