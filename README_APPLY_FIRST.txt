DAEJUNG NEXT MEGA PATCH 01

적용 방식:
1) 기존 livon_project 폴더를 백업
2) 이 압축을 풀고 나온 frontend / backend / ops / docs 폴더를 기존 프로젝트에 덮어쓰기
3) frontend 폴더에서:
   npm install
   npm run dev
4) 브라우저:
   http://localhost:5173

포함:
- 메인 홈쇼핑 화면 대형 개편
- LIVE 커머스 섹션
- AI 캐릭터 안내 시스템
- 관리자 통합 대시보드
- LIVON 코인/지갑 UI
- 3중 보안 상태 패널
- 운영 준비 문서
- Docker / 실행 스크립트 초안
