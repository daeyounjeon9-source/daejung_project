# DAEJUNG NEXT 연령대별 수요예측 패치

## 추가 파일

```text
src/
├─ App.jsx
├─ index.css
├─ lib/
│  └─ ageDemandForecastEngine.js
└─ components/
   └─ AgeDemandForecastPanel.jsx
```

## 적용 내용

- 10대~70대 연령대별 수요예측 점수
- 연령대별 성향 분석
- 접속 유도 방향
- 실수요 가능성 신호
- 실증데이터 누적 구조
- 관리자용 발전방향 자동 제안
- 검색/조회/라이브/상담/구매 행동을 점수로 반영

## 핵심 운영 전략

- 10~20대: 미래고객, 확산, 숏폼, 코인미션
- 30대: 생활필수품, 정기구매, 가족소비
- 40~50대: 즉시 매출 전환, 건강/식품/가전, 신뢰형 LIVE
- 60~70대: 상담형 구매, 큰 글씨 UI, 음성안내, 가족 대리주문

## 상용화 시 서버 연결 항목

- 회원 생년/연령대 통계
- 익명 방문자 연령 추정 데이터
- 검색/조회/장바구니/구매 로그
- 라이브 시청시간
- 상담 연결 데이터
- 쿠폰 클릭률
- 연령대별 구매전환율
- 개인정보·행태정보·맞춤추천 동의
