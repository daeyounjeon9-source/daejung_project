# DAEJUNG NEXT 선제예측 AI 프로세서 패치

## 추가/교체 파일

```text
src/
├─ App.jsx
├─ index.css
├─ lib/
│  └─ proactiveAIProcessor.js
└─ components/
   └─ ProactiveAIProcessorPanel.jsx
```

## 적용 기능

- 예측 못한 내용 자동 점검
- 미검증 실증데이터 경고
- 개인정보/행태정보 리스크 경고
- 코인 악용 가능성 경고
- 고령층 UI/결제 이탈 경고
- LIVE 시청 대비 구매전환 병목 경고
- 초거대기업 모방 가능성 경고
- 관리자 조치완료/재점검 기록
- 선제예측 스캔 실행
- 사용자 직접 점검항목 추가

## 운영 원칙

대정넥스트는 기능만 추가하는 플랫폼이 아니라,
AI가 부족한 점을 먼저 발견하고 관리자에게 조치 방향을 제안하는 구조로 가야 합니다.

## 상용화 시 연결할 서버 데이터

- 연령별 검색/조회/장바구니/구매 로그
- LIVE 시청시간과 구매전환율
- 쿠폰 클릭률
- 반품률
- 고객센터 문의
- 코인 지급/사용/악용 패턴
- 개인정보 동의/철회 로그
- 외부 시장 트렌드
- 경쟁사 가격/배송/혜택 변화
